# Сайт киноколледжа на React

SPA на React 19 + Vite + TypeScript с CSS-модулями. Пять разделов, адаптив,
попапы, вкладки, фильтры, карусель, страница «Сведения об образовательной
организации» по требованиям к сайтам учебных заведений.

Позже этот сайт был перенесён на WordPress с сохранением вёрстки — код переноса
и описание в отдельном репозитории.

## Запуск

```bash
npm install
cp src/config/contacts.example.ts src/config/contacts.ts
npm run dev
```

## Сборка и публикация

```bash
npm run build      # сборка в dist/
npm run deploy     # публикация на GitHub Pages
```

`base` для GitHub Pages задан в `vite.config.ts` — если репозиторий назван иначе,
поправьте там и в `homepage` в `package.json`.

## Про данные в репозитории

Это демонстрационная версия. Имена сотрудников, их фотографии и контакты
вымышленные: настоящие данные принадлежат заказчику и в репозиторий не входят.
Фотографии — сгенерированные заглушки. PDF-документы колледжа тоже исключены,
поэтому ссылки на них в демо не открываются.

Реальные контакты подставляются через `src/config/contacts.ts` — он в
`.gitignore`, рядом лежит `contacts.example.ts` с условными значениями.

## Структура

```
src/
├── components/   секции страниц
├── pages/        страницы-маршруты
├── ui/           переиспользуемые элементы (кнопки, попапы, вкладки, карточки)
├── assets/data/  контент разделов
├── config/       контакты
└── utils/        вспомогательные функции
```
